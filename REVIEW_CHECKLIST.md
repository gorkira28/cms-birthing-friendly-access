# Review checklist

- [x] Decision-relevant maternal-health question
- [x] Primary authoritative CMS and Census sources
- [x] Reproducible DuckDB SQL + Python pipeline
- [x] Frozen source snapshots with checksums
- [x] Explicit inclusion and exclusion rules
- [x] Exact Poisson confidence intervals
- [x] Statistical association reported with p-value
- [x] Automated QA tests
- [x] Recruiter-readable executive summary
- [x] Three portfolio-ready visuals
- [x] QGIS-ready GeoJSON and styling instructions
- [x] Data dictionary, methods, references, ethics, and limitations
- [x] Portfolio website case study
- [x] Human-sounding LinkedIn draft with link separated into first comment
- [x] No PHI, secrets, Texas DSHS data, fabricated results, or causal claims
- [ ] Kira's review and approval
- [ ] GitHub repository publication after approval
- [ ] Profile and portfolio website update after approval
- [ ] LinkedIn posting only after separate explicit approval
